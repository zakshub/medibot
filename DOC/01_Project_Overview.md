# 1. Project Overview

## 1.1 Project Name

`medic`

## 1.2 Documentation Goal

This documentation set creates a structured operating base for the project even before implementation files are present.

## 1.3 Why This Exists

The repository currently has no usable project files to document. Because of that, the correct move is to establish:

1. A consistent document order
2. A recommended folder layout
3. Naming and maintenance rules
4. Planning and status templates
5. A repeatable handoff process

## 1.4 Scope Of This Pack

This pack covers:

1. Current observed state
2. Recommended structure
3. Documentation standards
4. Execution workflow
5. Tracking templates
6. Change control

## 1.5 Scope Not Yet Covered

This pack does not yet include:

1. Actual code architecture
2. Real dependency inventory
3. Environment variables
4. Run commands
5. Production deployment steps

Those items should be added only after real project files exist.
