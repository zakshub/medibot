# 4. Document Naming Standard

## 4.1 Documentation File Format

Use this pattern for docs:

`NN_Clear_Descriptive_Name.md`

Examples:

1. `00_INDEX.md`
2. `05_Project_Setup_Workflow.md`
3. `10_Status_Tracker.md`

## 4.2 Numbering Rules

1. Use two digits for stable ordering
2. Reserve `00` for the index
3. Keep similar topics grouped in sequence
4. Add new files at the end unless a true reordering is necessary

## 4.3 Naming Rules

1. Use title-style words with underscores
2. Avoid vague labels like `notes.md` or `misc.md`
3. Keep one subject per document
4. Prefer durable names over temporary sprint labels

## 4.4 Folder Naming Rules

1. Use lowercase for working folders where practical
2. Keep names short and readable
3. Avoid duplicate meanings such as both `img` and `images`
4. Avoid spaces in technical working folders unless a platform workflow requires them

## 4.5 Versioning Rule

Do not create duplicate docs like `final`, `final2`, or `latest`. Maintain one authoritative document and track changes in the change log.
