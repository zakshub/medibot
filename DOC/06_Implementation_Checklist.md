# 6. Implementation Checklist

## 6.1 Foundation Checklist

1. Create the base project folders
2. Confirm the real project objective
3. Add initial source or working files
4. Add asset and content locations
5. Define output destination

## 6.2 Documentation Checklist

1. Update the repository state
2. Update the folder structure
3. List assets in the inventory
4. Record risks and blockers
5. Update status and change log

## 6.3 Quality Checklist

1. File names are consistent
2. Folders match their stated purpose
3. No duplicate working copies are left without reason
4. Deliverables are separated from raw inputs
5. Documentation reflects actual files

## 6.4 Handoff Checklist

1. Current status is written
2. Pending tasks are listed
3. Known risks are listed
4. Latest edits are recorded
5. Next operator can continue without guesswork
